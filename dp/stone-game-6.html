STONE GAME VI MEDIUM

problema

Há n pedras na mesa, mas Alice e Bob não concordam sobre quanto cada uma vale: para Alice, a pedra i vale aliceValues[i]; para Bob, vale bobValues[i]. Alice começa e os dois se alternam. Na sua vez, o jogador tira qualquer pedra que ainda esteja na mesa e soma o valor que ele dá a ela.

Os dois jogam de forma ótima. Retorne 1 se Alice terminar com mais pontos, −1 se Bob terminar com mais, e 0 se empatarem.

Continuação de Stone Game: aqui não há pontas, qualquer pedra pode ser pega.

Exemplo 1 · aliceValues = [1, 3], bobValues = [2, 1] → 1

Alice pega a pedra 1 (3 pontos) e Bob fica com a pedra 0 (2 pontos). 3 contra 2.

Exemplo 2 · aliceValues = [1, 2], bobValues = [3, 1] → 0

Alice pega a pedra 0, que vale só 1 para ela, mas 3 para Bob. Bob fica com a pedra 1 e faz 1. Empate em 1 a 1: se Alice pegasse a pedra 1, perderia por 2 a 3.

Exemplo 3 · aliceValues = [2, 4, 3], bobValues = [1, 6, 7] → −1 (o animado)

Qualquer que seja a jogada de Alice, Bob vence: o melhor que ela consegue é perder por 1 (6 a 7 ou 5 a 6).

Restrições: n == aliceValues.length == bobValues.length · 1 ≤ n ≤ 10⁵ · 1 ≤ aliceValues[i], bobValues[i] ≤ 100
