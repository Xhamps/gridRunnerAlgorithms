LONGEST COMMON SUBSEQUENCE MEDIUM

problema

Dadas duas strings a e b, retorne o tamanho da maior subsequência comum às duas. Se não existir nenhuma, retorne 0.

Uma subsequência é o que sobra de uma string depois de apagar zero ou mais caracteres, sem mudar a ordem dos que ficaram. "ACE" é subsequência de "ABCDE", mas "AEC" não é. Diferente de uma substring, os caracteres não precisam estar colados.

Exemplo 1 · a = "ABDCB", b = "ACBC" → 3

"ABC" aparece nas duas, nessa ordem: ABDCB e ACBC. Não existe nenhuma comum de tamanho 4.

Exemplo 2 · a = "GATO", b = "PATO" → 3

"ATO": só a primeira letra muda.

Exemplo 3 · a = "ABC", b = "XYZ" → 0

Nenhum caractere em comum.

Restrições: 1 ≤ a.length, b.length ≤ 1000 · as strings só têm letras
