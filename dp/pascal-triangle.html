PASCAL'S TRIANGLE EASY

problema

Monte as primeiras n linhas do triângulo de Pascal. A linha i tem i + 1 números: as duas pontas valem 1 e cada número do meio é a soma dos dois logo acima dele.

Cada número tem um significado: o da linha i, posição j, é C(i, j), a quantidade de jeitos de escolher j itens entre i. A soma vem de uma escolha: o último item entra (sobram j − 1 para escolher entre i − 1) ou não entra (sobram j entre i − 1).

Exemplo 1 · n = 5 → [[1], [1,1], [1,2,1], [1,3,3,1], [1,4,6,4,1]]

O 6 da última linha é 3 + 3, os dois números acima dele.

Exemplo 2 · n = 1 → [[1]]

Só o topo.

Restrições: 1 ≤ n ≤ 30
