STONE GAME IV HARD

problema

Agora existe uma única pilha com n pedras. Alice começa e os dois se alternam. Na sua vez, o jogador tira da pilha uma quantidade de pedras que seja um quadrado perfeito diferente de zero: 1, 4, 9, 16... Quem não consegue jogar (a pilha está vazia) perde.

Os dois jogam de forma ótima. Retorne true se Alice vencer.

A mesma dupla do Stone Game, mas aqui não se conta pedra: só importa quem fica sem jogada.

Exemplo 1 · n = 1 → true

Alice tira 1 pedra e Bob fica sem jogada.

Exemplo 2 · n = 2 → false

Alice só pode tirar 1. Bob tira a última e Alice fica sem jogada.

Exemplo 3 · n = 4 → true

4 é quadrado: Alice tira tudo de uma vez.

Exemplo 4 · n = 7 → false

Alice pode deixar 6 ou 3 pedras, e as duas posições são vencedoras para Bob.

Exemplo 5 · n = 17 → false

As jogadas deixam 16, 13, 8 ou 1 pedras, e em todas Bob tem uma resposta vencedora.

Exemplo animado · n = 10 → false

Sobrariam 9, 6 ou 1 pedras, todas posições vencedoras para Bob.

Restrições: 1 ≤ n ≤ 10⁵
