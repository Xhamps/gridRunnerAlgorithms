JUNTAR ARRAYS ORDENADOS EASY

problema

Você recebe dois arrays em ordem crescente. O array a tem tamanho m + n: as m primeiras casas guardam valores de verdade e as n últimas são só espaço reservado (valem 0 e devem ser ignoradas). O array b tem os outros n valores. Junte b dentro de a, no próprio a, de modo que ele termine com os m + n valores em ordem crescente. É exatamente o passo de "juntar" do merge sort.

Exemplo 1 · a = [2, 5, 7, 0, 0, 0], m = 3, b = [1, 4, 6] → [1, 2, 4, 5, 6, 7]

É o exemplo animado abaixo. Os três zeros finais são só lugar vago.

Exemplo 2 · a = [3], m = 1, b = [] → [3]

Nada para juntar: a já está pronto.

Exemplo 3 · a = [0], m = 0, b = [8] → [8]

Sem valores válidos em a: a única casa é ocupada pelo 8.

Restrições: 0 ≤ m, n ≤ 200 · 1 ≤ m + n ≤ 200 · -10⁹ ≤ valores ≤ 10⁹ · a e b em ordem crescente
