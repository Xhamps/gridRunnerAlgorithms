K-ÉSIMO MAIOR MEDIUM

problema

Dado um array de inteiros a, fora de ordem, e um número k, devolva o k-ésimo maior elemento: o que ficaria na posição k se o array fosse ordenado do maior para o menor. Repetidos contam cada um como uma posição, então não é o k-ésimo maior valor distinto.

Ordenar tudo resolve em O(n log n), mas a graça é fazer menos trabalho: só uma posição interessa.

Exemplo 1 · a = [3, 7, 1, 8, 2, 9, 5], k = 3 → 7

É o exemplo animado abaixo. Em ordem decrescente: 9, 8, 7, ... O terceiro é o 7.

Exemplo 2 · a = [3, 2, 3, 1, 2, 4, 5, 5, 6], k = 4 → 4

Decrescente: 6, 5, 5, 4. Os dois 5 ocupam duas posições.

Exemplo 3 · a = [-1, -5, 0, -3], k = 2 → -1

Negativos valem normalmente: o maior é 0 e o segundo é -1.

Restrições: 1 ≤ k ≤ n ≤ 10⁵ · -10⁴ ≤ a[i] ≤ 10⁴ · sem ordenar o array inteiro
