problema

Dado um array de inteiros a, coloque-o em ordem crescente mexendo no próprio array, sem criar uma cópia. Funções prontas de ordenação não valem. A ideia: escolha um pivô, empurre os menores para um lado e os maiores para o outro, e repita em cada lado.

Exemplo 1 · a = [4, 1, 5, 3, 2, 3] → [1, 2, 3, 3, 4, 5]

É o exemplo animado abaixo. O 3 aparece duas vezes, e cada aba trata o empate com o pivô de um jeito.

Exemplo 2 · a = [0, -7, 0, 9] → [-7, 0, 0, 9]

Negativos e repetidos são permitidos.

Exemplo 3 · a = [] → []

Array vazio (ou com um elemento só) já está ordenado.

Restrições: 0 ≤ n ≤ 5·10⁴ · -5·10⁴ ≤ a[i] ≤ 5·10⁴ · no lugar, sem sort embutido
