MERGE SORT MEDIUM

problema

Dado um array de inteiros a, devolva-o em ordem crescente. Funções prontas de ordenação estão proibidas, e a solução precisa rodar em O(n log n): algoritmos quadráticos como a bolha estouram o tempo com 50 mil elementos.

Exemplo 1 · a = [5, 2, 4, 6, 1, 3] → [1, 2, 3, 4, 5, 6]

É o exemplo animado abaixo. Com 6 elementos as metades não são iguais, então aparecem blocos de tamanhos diferentes.

Exemplo 2 · a = [3, -1, 3, 0] → [-1, 0, 3, 3]

Negativos e repetidos são permitidos; os repetidos ficam lado a lado.

Exemplo 3 · a = [7] → [7]

Um elemento só já está ordenado.

Restrições: 1 ≤ n ≤ 5·10⁴ · -5·10⁴ ≤ a[i] ≤ 5·10⁴ · tempo O(n log n), sem sort embutido
