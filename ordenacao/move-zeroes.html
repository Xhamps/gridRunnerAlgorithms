MOVER ZEROS EASY

problema

Dado um array de inteiros a, leve todos os zeros para o final. Os outros números precisam continuar na mesma ordem relativa em que apareciam. A mudança é feita no próprio array, sem criar uma cópia.

Exemplo 1 · a = [0, 1, 0, 3, 12] → [1, 3, 12, 0, 0]

É o exemplo animado abaixo. O 1 continua antes do 3, que continua antes do 12.

Exemplo 2 · a = [0] → [0]

Só um zero: já está no fim.

Exemplo 3 · a = [4, 0, -2] → [4, -2, 0]

Negativos contam como números comuns; só o 0 se move.

Restrições: 1 ≤ n ≤ 10⁴ · -2³¹ ≤ a[i] ≤ 2³¹ - 1 · memória extra O(1)
