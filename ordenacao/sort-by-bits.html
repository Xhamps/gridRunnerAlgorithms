ORDENÁVEL POR BITS MEDIUM

problema

Você recebe um array a de inteiros positivos. A única operação permitida é trocar dois vizinhos a[j] e a[j+1], e só quando os dois têm a mesma quantidade de bits 1 na escrita binária (o popcount). Pode repetir quantas vezes quiser. Diga se dá para deixar o array em ordem crescente.

Exemplo 1 · a = [8, 4, 2, 30, 15] → true

8, 4 e 2 têm um bit 1 cada (1000, 100, 10) e podem trocar entre si; 30 e 15 têm quatro (11110, 1111). Ordenando cada bloco sai [2, 4, 8, 15, 30].

Exemplo 2 · a = [1, 2, 3, 4, 5] → true

Já está em ordem: nenhuma troca é necessária.

Exemplo 3 · a = [1, 8, 4, 12, 3, 16] → false

É o exemplo animado. O 3 (popcount 2) precisa ir para antes do 4 e do 8 (popcount 1), mas para isso teria que trocar com eles, o que é proibido.

Restrições: 1 ≤ n ≤ 100 · 1 ≤ a[i] ≤ 256
