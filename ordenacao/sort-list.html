ORDENAR LISTA LIGADA MEDIUM

problema

Recebemos a cabeça head de uma lista simplesmente ligada: cada nó tem um valor e um ponteiro next para o seguinte. Devolva a cabeça da mesma lista em ordem crescente. Os nós não trocam de valor: quem muda de lugar são os ponteiros. A meta é tempo O(n log n).

Exemplo 1 · 4 → 2 → 5 → 1 → 3 → 1 → 2 → 3 → 4 → 5

É o exemplo animado abaixo. Com 5 nós a divisão sai desigual (3 + 2) e sobram blocos sem par.

Exemplo 2 · 2 → 1 → 2 → 1 → 2 → 2

Valores repetidos ficam lado a lado; com <= no merge, o primeiro 2 continua antes do segundo.

Exemplo 3 · lista vazia → lista vazia

Restrições: 0 ≤ n ≤ 5·10⁴ · -10⁵ ≤ val ≤ 10⁵ · sem acesso por índice: só dá para andar pelo next
