ORDENAR CORES MEDIUM

problema

Um array a guarda só os valores 0, 1 e 2, que representam as cores vermelho, branco e azul. Reorganize o array para que todos os vermelhos venham primeiro, depois os brancos e por fim os azuis. A mudança é feita no próprio array, com memória extra constante e sem usar a função de ordenação da linguagem. O desafio extra é fazer tudo numa única varredura.

Exemplo 1 · a = [1, 2, 0, 2, 1, 0, 1] → [0, 0, 1, 1, 1, 2, 2]

É o exemplo animado abaixo: dois vermelhos, três brancos e dois azuis.

Exemplo 2 · a = [2, 1, 0] → [0, 1, 2]

Cada cor aparece uma vez, na ordem inversa.

Exemplo 3 · a = [1, 1, 1] → [1, 1, 1]

Uma cor só: nada muda de lugar.

Restrições: 1 ≤ n ≤ 300 · a[i] ∈ {0, 1, 2} · memória extra O(1)
