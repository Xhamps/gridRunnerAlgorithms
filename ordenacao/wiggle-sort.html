ZIGUE-ZAGUE HARD

problema

Dado um array de inteiros a, reorganize os valores para que eles subam e desçam alternadamente: a[0] < a[1] > a[2] < a[3] > .... As desigualdades são estritas, então dois vizinhos nunca podem ser iguais. A entrada sempre tem pelo menos uma resposta, e qualquer resposta válida serve.

Exemplo 1 · a = [2, 3, 5, 3, 1, 3] → [3, 5, 2, 3, 1, 3]

É o exemplo animado abaixo. A mediana 3 aparece três vezes, e as três cópias precisam ficar separadas.

Exemplo 2 · a = [1, 5, 1, 1, 6, 4] → [1, 6, 1, 5, 1, 4]

Os três 1 ocupam todos os vales; [1, 4, 1, 5, 1, 6] também seria aceito.

Exemplo 3 · a = [4, 5, 5, 6] → [5, 6, 4, 5]

Intercalar as metades na ordem crescente daria [4, 5, 5, 6], com dois 5 vizinhos. De trás para frente, os 5 vão para as pontas.

Restrições: 1 ≤ n ≤ 5·10⁴ · 0 ≤ a[i] ≤ 5000 · sempre existe resposta · desafio extra: O(n) de tempo e O(1) de memória extra
