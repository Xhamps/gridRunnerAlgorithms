JUNTAR LISTAS ORDENADAS EASY

problema

Você recebe as cabeças de duas listas ligadas simples, a e b, cada uma já em ordem crescente. Junte as duas numa única lista crescente e devolva a cabeça dela. A junção é feita religando os nós que já existem: só os ponteiros next mudam, nenhum valor é copiado para um nó novo. É exatamente a etapa de "intercalar" do merge sort quando os dados estão numa lista ligada.

Exemplo 1 · a = 1 → 3 → 6, b = 2 → 3 → 7 → 9 → 1 → 2 → 3 → 3 → 6 → 7 → 9

É o exemplo animado abaixo. A lista A acaba primeiro, e o 7 → 9 de B entra de uma vez no final.

Exemplo 2 · a = null, b = 0 → 0

Uma lista vazia: a resposta é a outra, sem mexer em nada.

Exemplo 3 · a = null, b = null → null

Restrições: 0 ≤ tamanho de cada lista ≤ 50 · -100 ≤ val ≤ 100 · as duas listas já vêm em ordem crescente
