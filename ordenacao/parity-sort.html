PARES ANTES DOS ÍMPARES EASY

problema

Dado um array de inteiros a, reorganize-o no próprio lugar para que todos os números pares fiquem antes de todos os ímpares. Dentro de cada grupo a ordem não importa: qualquer arrumação com os pares na frente é aceita.

Exemplo 1 · a = [2, 3, 1, 4, 7, 6, 5] → [2, 6, 4, 1, 7, 3, 5]

É o exemplo animado abaixo. A aba Lomuto chega em [2, 4, 6, 3, 7, 1, 5], que também vale.

Exemplo 2 · a = [5] → [5]

Um único número já está separado.

Exemplo 3 · a = [-3, 0, 8] → [8, 0, -3] (ou [0, 8, -3])

Zero é par, e negativos seguem a mesma regra.

Restrições: 1 ≤ n ≤ 5·10⁴ · -10⁴ ≤ a[i] ≤ 10⁴ · memória extra O(1)
