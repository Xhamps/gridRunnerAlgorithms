ELEMENTO PICO MEDIUM

problema

Um pico é um elemento estritamente maior que os dois vizinhos. Dado um array a em que dois vizinhos nunca são iguais, devolva o índice de qualquer pico. Imagine que antes do começo e depois do fim existe -∞: assim as pontas também podem ser picos. O desafio é fazer isso em O(log n).

Exemplo 1 · a = [1, 3, 2, 4, 5, 7, 6, 2] → 1 ou 5

É o exemplo animado abaixo. Há dois picos: o 3 (índice 1) e o 7 (índice 5). A aba Linear acha o 1, a Binária acha o 5, e as duas respostas valem.

Exemplo 2 · a = [1, 2, 3] → 2

Só sobe: o último é pico, porque depois dele vem -∞.

Exemplo 3 · a = [5] → 0

Um elemento sozinho tem -∞ dos dois lados.

Restrições: 1 ≤ n ≤ 1000 · -2³¹ ≤ a[i] ≤ 2³¹ - 1 · a[i] ≠ a[i + 1] · tempo O(log n)
