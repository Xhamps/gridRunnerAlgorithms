POSIÇÃO DE INSERÇÃO EASY

problema

Você recebe um array a em ordem crescente, sem números repetidos, e um valor target. Se o target estiver no array, devolva o índice dele. Se não estiver, devolva o índice em que ele teria que entrar para o array continuar ordenado.

Exemplo 1 · a = [1, 3, 5, 6, 8, 10, 12], target = 7 → 4

É o exemplo animado abaixo. O 7 não está no array; ele ficaria entre o 6 (casa 3) e o 8, ocupando a casa 4.

Exemplo 2 · a = [1, 3, 5, 6], target = 5 → 2

O 5 está no array, na casa 2.

Exemplo 3 · a = [1, 3, 5, 6], target = 7 → 4

Maior que todos: entra depois do último, na casa n.

Exemplo 4 · a = [1, 3, 5, 6], target = 0 → 0

Menor que todos: entra na frente.

Restrições: 1 ≤ n ≤ 10⁴ · -10⁴ ≤ a[i], target ≤ 10⁴ · a crescente e sem repetidos · tempo esperado O(log n)
