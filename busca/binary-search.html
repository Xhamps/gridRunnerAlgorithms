BUSCA BINÁRIA EASY

problema

Dado um array a de inteiros distintos em ordem crescente e um valor target, devolva o índice em que target aparece, ou -1 se ele não estiver lá. A busca precisa rodar em O(log n): olhar casa por casa não vale.

Exemplo 1 · a = [-5, 0, 3, 8, 11, 17, 24], target = 11 → 4

É o exemplo animado abaixo: três sondagens (8, 17 e 11) bastam para 7 casas.

Exemplo 2 · a = [-5, 0, 3, 8, 11, 17, 24], target = 6 → -1

6 cairia entre o 3 e o 8; a faixa de candidatos fica vazia e a busca desiste.

Exemplo 3 · a = [2], target = 2 → 0

Um único elemento: a faixa começa com um candidato e ele precisa ser olhado.

Restrições: 1 ≤ n ≤ 10⁴ · -10⁴ < a[i], target < 10⁴ · valores distintos, em ordem crescente
