RAIZ QUADRADA INTEIRA EASY

problema

Dado um inteiro x ≥ 0, devolva a parte inteira da raiz quadrada dele, ou seja, o maior inteiro m tal que m · m ≤ x. A parte decimal é jogada fora (arredonda para baixo). Não vale usar funções prontas de raiz nem potência fracionária, como Math.sqrt(x) ou x ** 0.5.

Exemplo 1 · x = 40 → 6

É o exemplo animado abaixo. 6² = 36 ≤ 40, mas 7² = 49 já passa. A raiz real é 6,32…

Exemplo 2 · x = 16 → 4

Quadrado perfeito: a resposta é exata.

Exemplo 3 · x = 0 → 0

0² = 0, então 0 já é a resposta.

Restrições: 0 ≤ x ≤ 2³¹ - 1 · sem Math.sqrt, sem ** 0.5
