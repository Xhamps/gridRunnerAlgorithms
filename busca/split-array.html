DIVIDIR COM MENOR SOMA MÁXIMA HARD

problema

Dado um array a de inteiros não negativos e um inteiro k, corte a em exatamente k pedaços contíguos e não vazios. Cada pedaço tem uma soma; a pior delas é a maior. Escolha os cortes de modo que essa maior soma seja a menor possível e retorne esse valor.

Exemplo 1 · a = [7, 2, 5, 10, 8], k = 2 → 18

É o exemplo animado. Cortando em [7, 2, 5] | [10, 8] as somas são 14 e 18. Qualquer outro corte deixa um pedaço com mais de 18 (por exemplo [7, 2, 5, 10] | [8] dá 24).

Exemplo 2 · a = [1, 2, 3, 4, 5], k = 2 → 9

[1, 2, 3] | [4, 5]: somas 6 e 9.

Exemplo 3 · a = [1, 4, 4], k = 3 → 4

Com k = n, cada elemento fica sozinho e a resposta é o maior deles.

Restrições: 1 ≤ n ≤ 1000 · 0 ≤ a[i] ≤ 10⁶ · 1 ≤ k ≤ min(50, n)
