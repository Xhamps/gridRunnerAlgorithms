BUSCA EM ARRAY ROTACIONADO MEDIUM

problema

Um array crescente de números distintos foi rotacionado num ponto que você não conhece: um bloco do começo foi cortado e colado no fim, como [1, 2, 4, 5, 6, 7] virando [5, 6, 7, 1, 2, 4]. Dado esse array a e um valor target, devolva o índice de target em a, ou -1 se ele não estiver lá. A busca precisa ser O(log n): varrer o array inteiro não vale.

Exemplo 1 · a = [18, 21, 2, 4, 5, 7, 9, 10, 12, 13, 15], target = 5 → 4

É o exemplo animado abaixo. O degrau fica entre o 21 e o 2; o 5 está na parte da direita.

Exemplo 2 · a = [4, 5, 6, 7, 0, 1, 2], target = 3 → -1

O 3 cairia entre o 2 e o 4, mas não existe.

Exemplo 3 · a = [8], target = 8 → 0

Um elemento só: rotacionar não muda nada.

Restrições: 1 ≤ n ≤ 5000 · -10⁴ ≤ a[i], target ≤ 10⁴ · valores distintos · tempo O(log n)
