PATHFINDER · DIJKSTRA MEDIUM

problema

Um mapa é uma grade R × C de altitudes. Cada célula vale de 1 a 9, ou 0 quando é uma parede. Dá para andar para cima, para baixo, para a esquerda ou para a direita, e cada passo custa 1 + |altura de onde sai − altura para onde vai|: andar no plano custa 1, subir ou descer custa mais.

Retorne o menor custo total para ir do canto (0,0) ao canto (R−1,C−1), ou -1 se as paredes isolarem o destino.

Exemplo 1 · [[5,0,2],[6,7,2],[5,5,6]] → 7

Desce pela coluna da esquerda (5 → 6 → 5, custo 2 + 2) e anda pela última linha (5 → 5 → 6, custo 1 + 2). Atravessar o morro de altura 7 no meio sai mais caro.

Exemplo 2 · [[1,1,1],[1,1,1]] → 3

Terreno plano: o custo é o número de passos.

Exemplo 3 · [[3,0],[0,3]] → -1

As duas saídas da origem são paredes.

Restrições: 1 ≤ R, C ≤ 100 · cada célula vale de 0 a 9 · origem e destino não são paredes
